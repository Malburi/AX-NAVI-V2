AX-NAVI 사내 배포 가이드 (관리자용)

GitHub 에 접속되지 않는 사내망에 공유폴더 하나로 AX-NAVI 플러그인을 배포하고 갱신합니다.

구조 처음 올리기 사용자 안내 새 판 배포 DB 드라이버 스크립트가 하는 일 문의 대응

구조

관리자1. 공유폴더에 올린다저장소 전체를 \\파일서버\공유\ax-navi 에 복사합니다.
사용자2. install.cmd 실행각자 공유폴더의 deploy\install.cmd 를 실행합니다.
관리자3. 새 판이 나오면공유폴더를 덮어쓰고 사용자에게 2번 재실행을 알립니다.

스크립트는 공유폴더를 각 PC 의 %LOCALAPPDATA%\ax-navi\marketplace 로 복사해 그 폴더를 마켓플레이스로 등록합니다. 공유폴더를 직접 등록하지 않는 이유는 두 가지입니다. Claude Code 가 네트워크 경로 마켓플레이스를 기본으로 거부하고, 등록하더라도 플러그인을 그 경로에서 바로 실행하는데 Node 가 UNC 경로의 DB 도구를 띄우지 못하기 때문입니다.

GitHub 에 접속되는 사용자는 이 방식을 쓰지 않아도 됩니다. 한 PC 에는 둘 중 하나만 등록되며, 내용은 같은 저장소에서 오므로 판 번호만 같으면 차이가 없습니다.

처음 올리기

GitHub 에 접속되는 PC 에서 저장소를 받아 공유폴더로 복사합니다. zip 으로 받아 풀어도 됩니다.

git clone https://github.com/Malburi/AX-NAVI-V2.git C:\temp\ax-navi
robocopy C:\temp\ax-navi \\파일서버\공유\ax-navi /MIR /XD .git C:\temp\ax-navi\deploy\oracle-driver
  • 공유폴더 바로 아래에 .claude-plugin\marketplace.json 과 deploy\install.cmd 가 있어야 합니다.
  • .git 폴더는 필요 없습니다.
  • 권한은 사용자에게 읽기, 관리자에게 쓰기를 줍니다.
  • /XD ...\oracle-driver 는 공유폴더에 따로 넣어 둔 DB 드라이버를 /MIR 가 지우지 않게 하려는 것입니다.

사용자 안내

사용자에게는 아래 두 가지만 알리면 됩니다.

  • 실행 파일: \\파일서버\공유\ax-navi\deploy\install.cmd
  • 설명서: \\파일서버\공유\ax-navi\deploy\user-guide.html

사용자 PC 에는 Claude Code 와 Node.js 18 이상이 있어야 합니다. Git 은 필요 없습니다.

새 판 배포

  1. 새 판의 .claude-plugin\plugin.json 에서 version 이 지금 공유폴더의 판보다 올라갔는지 확인합니다.
  2. 저장소를 다시 받아(git pull) 위와 같은 robocopy 명령으로 공유폴더를 덮어씁니다.
  3. 사용자에게 Claude Code 를 닫고 install.cmd 를 다시 실행하라고 알립니다.
버전 번호가 올라간 판만 배포하세요. Claude Code 는 플러그인을 버전별로 보관하므로 version 이 같으면 내용이 바뀌어도 이미 설치한 PC 에 반영되지 않습니다. 사용자 창에 이미 최신판입니다 가 나오는데 새 내용이 안 보인다는 문의는 대부분 이 경우입니다.

사용자가 복사하는 도중에 덮어쓰면 반쪽짜리 판을 받을 수 있습니다. 사용이 적은 시간에 올리거나, 옆 폴더(ax-navi.new)에 먼저 복사한 뒤 이름을 바꿔 교체하세요.

DB 드라이버 미리 넣기 (폐쇄망)

DB 도구는 처음 쓸 때 npm install oracledb@6.10.0 을 실행합니다. 사용자 PC 가 npm 레지스트리에 접속하지 못하면 둘 중 하나로 해결합니다.

방법 1. 사내 npm 저장소가 있을 때

사용자 PC 에서 한 번만 설정하게 안내합니다. 공유폴더에 따로 넣을 것은 없습니다.

npm config set registry http://사내-nexus/repository/npm/

방법 2. 공유폴더에 드라이버를 같이 둘 때

인터넷이 되는 PC 에서 아래 명령으로 공유폴더의 deploy\oracle-driver 에 드라이버를 받아 둡니다.

npm install oracledb@6.10.0 --prefix \\파일서버\공유\ax-navi\deploy\oracle-driver --no-audit --no-fund --ignore-scripts

그러면 install.cmd 가 각 PC 의 %USERPROFILE%\.claude\plugins\data\ax-navi-ax-navi 로 드라이버를 복사합니다. 이 드라이버(thin 모드)는 순수 JS 라 Oracle Client 없이 동작합니다. 플러그인이 요구하는 드라이버 버전이 바뀌면 이 폴더도 새로 받아야 합니다.

로그온 트리거가 있어 ORA-04088·ORA-20001 로 thin 접속을 거부하는 DB 는 사용자 PC 에 Oracle Client(Instant Client)가 필요합니다. 설치한 뒤 ORACLE_HOME 이나 AXNAVI_DB_CLIENT_LIB 를 잡으면 thick 모드로 접속합니다.

스크립트가 하는 일

install.cmd 는 실행 창구입니다. .ps1 은 더블클릭하면 메모장으로 열리고 회사 PC 는 PowerShell 스크립트 실행을 막아 두는 경우가 많아, 그 한 번만 실행을 허용해 install.ps1 을 돌립니다. PC 의 보안 설정은 바꾸지 않습니다.

단계하는 일
확인공유폴더에 .claude-plugin 이 있는지, claude·node 명령이 있는지 봅니다.
1. 복사robocopy /MIR 로 공유폴더를 %LOCALAPPDATA%\ax-navi\marketplace 에 맞춥니다(.git·드라이버 폴더 제외).
2. 등록그 폴더를 ax-navi 마켓플레이스로 등록합니다. 같은 이름이 GitHub 등 다른 곳을 가리키면 지우고 바꿉니다. 이미 등록돼 있으면 목록만 새로 읽습니다.
3. 설치ax-navi@ax-navi 를 사용자 범위로 설치하거나 갱신합니다.
4. 드라이버deploy\oracle-driver 가 있고 PC 의 판과 다르면 복사합니다.

다른 마켓플레이스와 플러그인, Claude Code 설정 파일은 직접 건드리지 않습니다.
