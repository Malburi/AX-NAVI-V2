AX-NAVI 사내 설치 가이드

GitHub 에 접속하지 않고 사내 공유폴더 하나로 AX-NAVI 플러그인을 설치하고 갱신합니다.

한눈에 보기 사용자 설치 관리자 배포 새 판 배포 DB 드라이버 문제 해결 제거

한눈에 보기

관리자1. 공유폴더에 올린다저장소 전체를 \\파일서버\공유\ax-navi 에 복사합니다.
사용자2. install.cmd 실행공유폴더의 deploy\install.cmd 를 더블클릭합니다.
사용자3. Claude Code 재시작끝입니다. 새 판이 올라오면 2번을 다시 실행합니다.
GitHub 에 접속되는 사람은 이 스크립트를 쓰지 않아도 됩니다. 지금처럼 GitHub 에서 설치·갱신하면 되고, 새 판도 관리자가 공유폴더에 올리기 전에 바로 받습니다. 
claude plugin marketplace update ax-navi
claude plugin update ax-navi@ax-navi
마켓플레이스 이름이 같아 한 PC 에는 둘 중 하나만 등록됩니다. GitHub 사용자가 install.cmd 를 실행하면 공유폴더 방식으로 바뀌고, 그 뒤로는 공유폴더가 갱신돼야 새 판을 받습니다. GitHub 으로 되돌리려면 아래처럼 합니다. 
claude plugin marketplace remove ax-navi
claude plugin marketplace add Malburi/AX-NAVI-V2
claude plugin install ax-navi@ax-navi

설치 스크립트는 공유폴더를 PC 의 %LOCALAPPDATA%\ax-navi\marketplace 로 복사한 뒤 그 폴더를 Claude Code 마켓플레이스로 등록합니다. 공유폴더를 직접 등록하지 않는 이유는 Claude Code 가 네트워크 경로 마켓플레이스를 기본으로 막고, 등록하더라도 DB 도구가 네트워크 경로에서 실행되지 않기 때문입니다.

사용자설치하기

필요한 것

항목설명
Claude Code명령 창에서 claude --version 이 동작해야 합니다.
Node.js 18 이상명령 창에서 node --version 이 동작해야 합니다. 플러그인의 인덱서와 DB 도구가 Node 로 돌아갑니다.
공유폴더 읽기 권한탐색기에서 \\파일서버\공유\ax-navi 가 열려야 합니다.

순서

  1. 열려 있는 Claude Code 를 모두 닫습니다.
  2. 탐색기에서 \\파일서버\공유\ax-navi\deploy 를 열고 install.cmd 를 더블클릭합니다.
  3. 창에 완료: ax-navi 0.x.x 가 나오면 아무 키나 눌러 닫습니다.
  4. Claude Code 를 다시 실행하고 /plugin 에서 ax-navi 가 켜져 있는지 확인합니다.

정상이면 창에 아래처럼 나옵니다.

  복사했습니다.
[2/4] 마켓플레이스 등록
  등록했습니다.
[3/4] 플러그인 설치
  설치했습니다.
[4/4] Oracle DB 드라이버
  oracledb 6.10.0 를 복사했습니다.

완료: ax-navi 0.3.12
예전에 GitHub 에서 ax-navi 를 설치했던 PC 도 그대로 실행하면 됩니다. 스크립트가 기존 등록을 지우고 공유폴더 판으로 바꿉니다. 플러그인은 사용자 범위로 설치되어 모든 프로젝트에서 쓰입니다.

DB 도구 쓰기 (선택)

Oracle 패키지·프로시저·트리거를 분석하려면 Claude Code 에서 아래 명령으로 접속 정보를 넣습니다. 비워 두면 DB 도구는 꺼진 채로 남습니다.

/plugin configure ax-navi@ax-navi

프로젝트마다 DB 가 다르면 그 프로젝트의 .env 에 ORACLE_HOST·ORACLE_PORT·ORACLE_SERVICE·ORACLE_USER·ORACLE_PASSWORD 를 두면 그쪽이 우선합니다.

반드시 읽기 전용 계정(CREATE SESSION + SELECT_CATALOG_ROLE)을 쓰세요. Windows 에서는 플러그인 설정의 비밀번호가 %USERPROFILE%\.claude\.credentials.json 에 평문으로 저장됩니다. .env 에 비밀번호를 두었다면 그 파일이 git 에 올라가지 않게 .gitignore 에 넣으세요.

관리자공유폴더에 올리기

GitHub 에 접속되는 PC 에서 저장소를 받아 공유폴더로 복사합니다. zip 으로 받아 풀어도 됩니다.

git clone https://github.com/Malburi/AX-NAVI-V2.git C:\temp\ax-navi
robocopy C:\temp\ax-navi \\파일서버\공유\ax-navi /MIR /XD .git C:\temp\ax-navi\deploy\oracle-driver
  • 공유폴더 바로 아래에 .claude-plugin\marketplace.json 과 deploy\install.cmd 가 있어야 합니다.
  • .git 폴더는 필요 없습니다.
  • 권한은 사용자에게 읽기, 관리자에게 쓰기를 줍니다.
  • 사용자에게는 \\파일서버\공유\ax-navi\deploy\install.cmd 경로와 이 문서(deploy\install-guide.html)를 안내합니다.

위 robocopy 의 /XD ...\oracle-driver 는 공유폴더에 따로 넣어 둔 DB 드라이버를 /MIR 가 지우지 않게 하려는 것입니다.

관리자새 판 배포

  1. 새 판을 받아 위와 같은 robocopy 명령으로 공유폴더를 덮어씁니다.
  2. 사용자에게 install.cmd 를 다시 실행하라고 알립니다. 창에 0.3.12 에서 0.3.13 으로 갱신했습니다 처럼 나옵니다.
버전 번호가 올라간 판만 배포하세요. Claude Code 는 플러그인을 버전별로 보관하므로 .claude-plugin\plugin.json 의 version 이 같으면 내용이 바뀌어도 이미 설치한 PC 에 반영되지 않습니다. 사용자 창에 이미 최신판입니다 가 나오는데 내용이 안 바뀌었다면 이 경우입니다.

사용자가 공유폴더를 복사하는 도중에 덮어쓰면 반쪽짜리 판을 받을 수 있습니다. 사용자가 적은 시간에 올리거나, 옆 폴더(ax-navi.new)에 먼저 복사한 뒤 이름을 바꿔 교체하세요.

관리자DB 드라이버 미리 넣기 (폐쇄망)

DB 도구는 처음 쓸 때 npm install oracledb@6.10.0 을 실행합니다. 사용자 PC 가 npm 레지스트리에 접속하지 못하면 둘 중 하나로 해결합니다.

방법 1. 사내 npm 저장소가 있을 때

사용자 PC 에서 한 번만 설정합니다. 공유폴더에 따로 넣을 것은 없습니다.

npm config set registry http://사내-nexus/repository/npm/

방법 2. 공유폴더에 드라이버를 같이 둘 때

인터넷이 되는 PC 에서 아래 명령으로 공유폴더의 deploy\oracle-driver 에 드라이버를 받아 둡니다.

npm install oracledb@6.10.0 --prefix \\파일서버\공유\ax-navi\deploy\oracle-driver --no-audit --no-fund --ignore-scripts

그러면 install.cmd 가 4단계에서 드라이버를 각 PC 의 %USERPROFILE%\.claude\plugins\data\ax-navi-ax-navi 로 복사합니다. 이 드라이버(thin 모드)는 순수 JS 라 Oracle Client 없이 동작합니다.

접속 계정에 로그온 트리거가 있어 ORA-04088·ORA-20001 로 거부되는 DB 는 Oracle Client(Instant Client)가 필요합니다. 설치한 뒤 환경 변수 ORACLE_HOME 이나 AXNAVI_DB_CLIENT_LIB 를 잡아 주면 thick 모드로 접속합니다.

문제 해결

창에 나온 내용할 일
claude 명령을 찾지 못했습니다Claude Code 를 설치한 뒤 새 창(새 탐색기)에서 다시 실행합니다.
node 명령을 찾지 못했습니다Node.js 18 이상을 설치한 뒤 다시 실행합니다.
원본 폴더에 .claude-plugin\marketplace.json 이 없습니다공유폴더에 저장소 전체가 올라가 있는지 관리자가 확인합니다.
공유폴더를 복사하지 못했습니다Claude Code 를 모두 닫고 다시 실행합니다. 계속되면 공유폴더 읽기 권한을 확인합니다.
이미 최신판입니다 (그런데 내용이 그대로)관리자가 버전 번호를 올리지 않은 판을 올린 경우입니다. 새 판 배포를 보세요.
DB 도구에서 "드라이버를 자동 설치하지 못했습니다"DB 드라이버 미리 넣기 중 하나를 한 뒤 install.cmd 를 다시 실행합니다.
DB 도구에서 ORA-04088 / ORA-20001Oracle Client 를 설치하고 ORACLE_HOME 을 잡습니다(위 설명).

Claude Code 안에서는 /plugin 으로 설치 상태를, /mcp 에서 plugin:ax-navi:db 가 ✔ Connected 인지 확인할 수 있습니다.

claude plugin uninstall ax-navi@ax-navi

rmdir /s /q "%LOCALAPPDATA%\ax-navi"
