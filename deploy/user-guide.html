AX-NAVI 설치 가이드 (사용자용)

사내 공유폴더에서 AX-NAVI 플러그인을 설치하고 새 판으로 갱신합니다.

한눈에 보기 설치하기 Python 설치 새 판 받기 DB 도구 쓰기 문제 해결 제거

한눈에 보기

1. Claude Code 닫기열려 있는 Claude Code 창을 모두 닫습니다.
2. install.cmd 실행공유폴더의 deploy\install.cmd 를 더블클릭합니다.
3. Claude Code 다시 열기끝입니다. 새 판이 나오면 2번을 다시 실행합니다.
GitHub 에 접속되는 PC 라면 이 스크립트를 쓰지 않아도 됩니다. 지금처럼 GitHub 에서 설치·갱신하면 되고, 새 판도 더 빨리 받습니다. 
claude plugin marketplace update ax-navi
claude plugin update ax-navi@ax-navi
GitHub 으로 쓰던 PC 에서 install.cmd 를 실행하면 공유폴더 방식으로 바뀝니다. 되돌리려면 아래처럼 합니다. 
claude plugin marketplace remove ax-navi
claude plugin marketplace add Malburi/AX-NAVI-V2
claude plugin install ax-navi@ax-navi

설치하기

필요한 것

항목확인 방법
Claude Code명령 창에서 claude --version 이 동작해야 합니다.
Node.js 18 이상명령 창에서 node --version 이 동작해야 합니다.
Python 3.10 이상명령 창에서 python --version 이 3.10 이상으로 나와야 합니다. 하네스 초기화(CLAUDE.md·스킬 조립, 검증, 위키 생성)에 필요합니다. 없어도 설치는 되지만 install.cmd 가 경고를 띄웁니다. 설치 방법은 Python 설치 를 보세요.
공유폴더 접근탐색기에서 관리자가 알려 준 공유폴더(예: \\파일서버\공유\ax-navi)가 열려야 합니다.

순서

  1. 열려 있는 Claude Code 를 모두 닫습니다.
  2. 탐색기에서 공유폴더의 deploy 폴더를 열고 install.cmd 를 더블클릭합니다.
  3. 창에 완료: ax-navi 0.x.x 가 나오면 아무 키나 눌러 닫습니다.
  4. Claude Code 를 다시 열고 /plugin 에서 ax-navi 가 켜져 있는지 확인합니다.

정상이면 창에 아래처럼 나옵니다.

  복사했습니다.
[2/4] 마켓플레이스 등록
  등록했습니다.
[3/4] 플러그인 설치
  설치했습니다.

완료: ax-navi 0.3.13
  • 설치는 사용자 범위라 모든 프로젝트에서 쓰입니다.
  • ax-navi 만 설치·갱신합니다. 다른 플러그인은 건드리지 않습니다.
  • 실행 파일은 install.cmd 입니다. 옆의 install.ps1 은 실제 작업을 하는 스크립트라 따로 실행하지 않습니다.

Python 설치

하네스 초기화(CLAUDE.md·스킬 조립, 검증, 위키 생성)에는 Python 3.10 이상이 필요합니다. 없으면 install.cmd 가 노란 경고를 띄우고, 하네스 초기화는 시작할 때 멈춥니다. 플러그인의 다른 기능(찾기·흐름 추적·DB 도구 등)은 Python 없이도 동작합니다.

  1. python.org 에서 Python 3.10 이상 설치 파일을 받아 실행합니다. 첫 화면 아래의 Add python.exe to PATH 를 반드시 체크한 뒤 설치합니다.
  2. 설정 > 앱 > 고급 앱 설정 > 앱 실행 별칭 에서 python.exe·python3.exe 를 끕니다. Microsoft Store 로 연결되는 가짜 실행 파일이라, 켜 두면 설치한 Python 대신 이것이 잡힐 수 있습니다.
  3. 새 명령 창에서 확인합니다. 
    python --version
Python 3.12.x
    3.10 이상으로 나오면 Claude Code 를 다시 열고 하네스 초기화를 요청합니다.
인터넷이 막힌 PC 라면 관리자에게 Python 설치 파일을 공유폴더에 올려 달라고 요청하세요.

새 판 받기

관리자가 새 판을 올렸다고 알리면 Claude Code 를 닫고 install.cmd 를 다시 실행합니다. 창에 0.3.12 에서 0.3.13 으로 갱신했습니다 처럼 나오면 됩니다.

바뀐 내용은 공유폴더의 docs\changelog.md 에 있습니다.

DB 도구 쓰기 (선택)

Oracle 패키지·프로시저·트리거를 분석하려면 Claude Code 에서 아래 명령으로 접속 정보를 넣습니다. 비워 두면 DB 도구는 꺼진 채로 남습니다.

/plugin configure ax-navi@ax-navi

프로젝트마다 DB 가 다르면 그 프로젝트의 .env 에 ORACLE_HOST·ORACLE_PORT·ORACLE_SERVICE·ORACLE_USER·ORACLE_PASSWORD 를 두면 그쪽이 우선합니다.

반드시 읽기 전용 계정을 쓰세요. Windows 에서는 플러그인 설정의 비밀번호가 %USERPROFILE%\.claude\.credentials.json 에 평문으로 저장됩니다. .env 에 비밀번호를 두었다면 그 파일이 git 에 올라가지 않게 .gitignore 에 넣으세요.

Claude Code 의 /mcp 에서 plugin:ax-navi:db 가 ✔ Connected 이면 준비된 것입니다.

문제 해결

창에 나온 내용할 일
claude 명령을 찾지 못했습니다Claude Code 를 설치한 뒤 다시 실행합니다.
node 명령을 찾지 못했습니다Node.js 18 이상을 설치한 뒤 다시 실행합니다.
[경고] Python 을 찾지 못했습니다 / 3.10 보다 낮습니다설치는 끝까지 진행됩니다. Python 설치 순서대로 하면 됩니다. 요약하면 python.org 에서 Python 3.10 이상을 받아 설치하고, 첫 화면에서 Add python.exe to PATH 를 체크합니다. 설정 > 앱 > 고급 앱 설정 > 앱 실행 별칭에서 python.exe·python3.exe 를 끈 뒤, 새 창에서 python --version 을 확인하고 Claude Code 를 다시 엽니다.
하네스 초기화가 "Python 3.10 이상이 필요합니다" 로 멈춤위와 같이 Python 3.10 이상을 설치한 뒤 하네스 초기화를 다시 실행합니다.
원본 폴더에 .claude-plugin\marketplace.json 이 없습니다관리자에게 공유폴더 상태를 문의합니다.
공유폴더를 복사하지 못했습니다Claude Code 를 모두 닫고 다시 실행합니다. 계속되면 관리자에게 공유폴더 권한을 문의합니다.
이미 최신판입니다 (그런데 새 기능이 안 보임)관리자에게 알립니다. 공유폴더에 버전 번호가 올라가지 않은 판이 올라간 경우입니다.
DB 도구에서 "드라이버를 자동 설치하지 못했습니다"관리자에게 DB 드라이버를 공유폴더에 넣어 달라고 한 뒤 install.cmd 를 다시 실행합니다.
DB 도구에서 ORA-04088 / ORA-20001그 DB 는 Oracle Client 가 필요합니다. 설치한 뒤 환경 변수 ORACLE_HOME 을 잡고 Claude Code 를 다시 엽니다.

해결되지 않으면 install.cmd 창의 내용을 그대로 복사해 관리자에게 보내 주세요.
